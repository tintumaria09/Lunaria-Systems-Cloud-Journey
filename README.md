# 🌙 Lunaria Systems - Cloud Journey

## About

**Lunaria Systems** is a fictional technology company created for educational and portfolio purposes.

This repository documents my journey of learning Linux, AWS, Cloud Computing, and DevOps by building and managing the infrastructure of a fictional company from the ground up.

Instead of learning technologies as isolated topics, I chose a project-based approach where every concept is learned by solving realistic engineering problems. As Lunaria Systems grows, its infrastructure will grow with it—from a single Linux server to a complete cloud-native environment.

The goal is not only to learn how different technologies work, but also to understand why they exist, when they should be used, and how they work together to solve real-world problems.

---

## Learning Objectives

This journey is designed to help me:

* Build a strong foundation in Linux System Administration (RHCSA/RHCE concepts)
* Prepare for the AWS Certified Solutions Architect – Associate certification
* Learn DevOps through practical, production-style projects
* Understand networking, security, storage, and system administration
* Learn Infrastructure as Code using Terraform
* Build CI/CD pipelines
* Learn Docker and Kubernetes
* Develop documentation and engineering best practices
* Build a professional portfolio that demonstrates practical experience

---

## Learning Philosophy

Every project follows the same engineering process:

1. Understand the business problem.
2. Design the solution.
3. Build the infrastructure manually.
4. Document every decision and configuration.
5. Improve and automate the solution using modern DevOps tools.

By first solving problems manually, I aim to understand the purpose behind every tool before automating the process.
